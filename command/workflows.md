---
description: View running and completed workflows
---

Show all active and recently completed ultracode workflows.

`/workflows` prints the current workflow list (id, title, status, agent count).

To manage a specific workflow, ask the agent — it drives the `workflow-manager`
tool, which supports:

- output  — view a workflow's summarized result
- pause   — pause a running workflow
- resume  — resume a paused workflow
- stop    — stop a running workflow
- save    — save a workflow as a reusable /<name> slash command
